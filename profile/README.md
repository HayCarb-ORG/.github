# Haycarb PLC — Technology Division

**Haycarb PLC** is the world's leading manufacturer of coconut shell-based activated carbon, established in 1973 and headquartered in Sri Lanka. With operations spanning Thailand, Indonesia, and distribution across 75+ countries, Haycarb serves critical industries including water treatment, air purification, gold recovery, and food & beverage processing.

This GitHub organization hosts the internal digital transformation initiatives of Haycarb's Technology Division — software systems, data platforms, and automation tools built to support manufacturing, sales, and operations at scale.

---

## About This Organization

The Haycarb Technology Division develops and maintains enterprise software that underpins our global operations. Our work spans operational intelligence, process automation, supply chain visibility, and sales analytics — all aligned to Haycarb's broader mission of responsible, efficient carbon manufacturing.

Our repositories reflect internal projects that have been selectively published to facilitate collaboration, version control, and structured development practices across our teams.

---

## Focus Areas

**IoT & Industrial Automation**

ERP integration, customer-facing portals, internal operations platforms, and cross-system data integration.

**Sustainability Technology**  
Digital tools supporting Haycarb's commitment to sustainable and responsible activated carbon production.

## Development Standards

All repositories maintained under this organization follow internal engineering guidelines:

- Code must be reviewed before merging to main branches
- Commit messages should be descriptive and reference relevant context
- New features must include appropriate documentation updates
- Security-sensitive configuration (credentials, API keys, environment variables) must never be committed to source control
- Issues and pull requests should follow the templates provided in each repository

---

## Contributing

This organization is primarily maintained by the Haycarb Technology Division. External contributions are not accepted for most repositories. For internal contributors:

1. Clone or fork the relevant repository
2. Create a feature branch: `git checkout -b feature/your-feature-name`
3. Commit with a clear message: `git commit -m "Describe the change"`
4. Push and open a pull request against the `main` branch
5. Request a review from a designated team member
